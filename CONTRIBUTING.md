# Contributing

Use synthetic tasks in issues and pull requests. State the command, expected behavior, observed result and environment. Do not upload browser profiles, credentials, real prompts, task logs or private source files.

Keep manual handoff usable without dependencies. Preserve bounded retries, explicit execution opt-ins, packet validation, and source/license pins. Do not introduce private APIs or credential export. Add behavior-level tests and run `sh scripts/check.sh` for code changes. Contributions must be shareable under MIT, with third-party notices preserved.
